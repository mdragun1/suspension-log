# Suspension Log

A small phone-first page for logging mountain bike suspension settings: several bikes, several setups per bike, a history of every saved change, notes, tyre pressure in psi or bar, and a service log.

Everything is stored in the browser on the device you use. Nothing is uploaded. Use Settings > Export backup to keep a copy.

To put it on an iPhone home screen: open the page in Safari, tap Share, then Add to Home Screen.
